# CyberShield AI 🔐

A lightweight cybersecurity toolkit for detecting phishing emails, suspicious URLs, and brute-force login attempts.

## 🚀 Features

- 📧 Phishing Email Detection using keyword + pattern analysis  
- 🌐 Suspicious URL Analyzer (domain + structure checks)  
- 🔐 Basic Login Attempt Monitor (brute-force detection logic)  

## 🧠 Objective

To demonstrate foundational cybersecurity awareness by building a simple but functional threat detection system.

## 🛠️ Tech Stack

- Python 3
- String Pattern Analysis
- Rule-based Detection Logic

## 📂 Files Included

- cybershield.py → Main project code  
- CyberShield_AI_Project_Report.pdf → Detailed explanation report  
- Project_Report.txt → Summary notes  

## 📊 Output

Classifies input as:
- ✅ SAFE
- ⚠️ SUSPICIOUS
- 🚨 HIGH RISK

## 📌 Future Improvements
